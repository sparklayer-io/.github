# Security

## Reporting a vulnerability

Please don't report security issues in GitHub issues, pull requests or discussions.

Email [support@sparklayer.io](mailto:support@sparklayer.io) with `URGENT - Security` in the subject line. This sends the report straight to our incident response.

Include what you can:

- the affected product, repository or URL
- steps to reproduce
- the impact you expect

Our [incident management policy](https://www.sparklayer.io/trust/incident-management/) covers what happens next.
